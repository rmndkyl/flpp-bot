# FLPP.io Bot — Solana Swap Volume Farming

Automated swap volume farming bot for **FLPP.io** (Flipper DEX) — AI-powered Solana DEX aggregator.

## Features

- 🔄 **Swap Execution** — Best-route swaps across Whirlpool, Quantum, AlphaQ, Manifest
- 📊 **Volume Farming** — Multi-round buy/sell cycles for leaderboard points
- 👛 **Multi-Wallet** — Process unlimited wallets from privateKey.txt
- 🌐 **Proxy Support** — Monosans free proxies, private proxy.txt, or direct
- ⏰ **Daily Mode** — Unattended cron execution with `--daily` flag
- 📈 **Market Pulse** — Browse trending tokens by organic score

## How It Works

1. Gets best swap quote from Flipper API (aggregates 4+ Solana DEXes)
2. Builds Solana transaction from swap instructions
3. Signs and sends transaction on-chain
4. Repeats buy/sell cycles for volume accumulation
